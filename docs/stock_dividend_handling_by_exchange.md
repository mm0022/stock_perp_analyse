# 各交易所「股票合约分红派息」处理分析

> 目的:梳理各交易所对**标的股票发生分红派息 / 送股 / 合股(反向拆分)等公司行动**时,
> 分别如何处理**现货资产**(代币化股票现货,如 xStocks)与**合约持仓**(股票永续 / 交割合约)。
> 核心问题:除息造成标的价格自然跳空,交易所用什么机制让持有人「盈亏中性」。

---

## 0. 一句话结论

- **合约(永续)**:多数交易所**不改你的持仓数量**,而是用一次**特殊资金费(special funding)**把除息跳空补给对的一方 → 数量不变,靠"价格 + 现金流"抹平。
- **现货(代币化股票)**:更接近真股票 → 现金分红通常**空投现金/稳定币**到账;送股/拆分则**调整持仓数量与单价**。
- 两者殊途同归:**总价值 ≈ 不变**,只是"数量变 vs 现金变"的表现形式不同。

---

## 1. 分析维度框架(填任何交易所都套这张表)

分析一个交易所的处理,只需回答下面几个问题:

| 维度 | 关注点 |
|------|--------|
| **产品类型** | 代币化股票现货 / 股票永续 / 股票交割合约 |
| **公司行动类型** | 现金股息 / 股票股息(送股)/ 现金+送股 / 拆股 / 合股(反向拆分) |
| **持仓数量是否变化** | 合约通常不变;现货通常变 |
| **补偿机制** | 特殊资金费 / 现金空投 / 数量与成本价重算 / 指数复权 |
| **方向与符号** | 除息=价格下跌→补多头;合股=价格上涨→补空头 |
| **时点** | 除息日(ex-date)前一天还是当天?按标的市场时区 |
| **是否有防套利/防操纵措施** | 只减仓模式、偏离阈值收紧、绕过费率上限 |
| **税** | 现金分红是否按税后(预扣税)补偿 → 决定是否严格中性 |

## 2. 现货资产 vs 合约持仓:本质区别

以 **10 送 1(送股 10%,r=0.1)、除息前价格 1000** 为例:

| | 真股票 / 代币化现货 | 股票永续合约 |
|---|---|---|
| 你持有的东西 | 真实份额 | 衍生品仓位(无实际股份) |
| 送股后持仓数量 | 10 → 11 股 | **仍为 10(不变)** |
| 每股价格 | 1000 → ~909 | 1000 → ~909(标记/指数跟随) |
| 补偿形式 | **多拿 1 股**(或现金空投) | **收到 ≈909 USDT 特殊资金费** |
| 结算后总价值 | 11 × 909 ≈ 10000 | 10 × 909 + 909 ≈ 10000 |
| 净变化 | ≈ 0 | ≈ 0 |

> 关键直觉:**送股改的是"价格",不是合约的"仓位数量";补偿走的是"资金费",不是"送你币"。**
> 除息后你会看到价格从 1000 "莫名"掉到 ~909,这不是亏 —— 必须配套那笔 ~909 的资金费一起看才是真实盈亏。

## 4. Binance 股票永续:分红处理详解 ✅

> 数据来源:Binance 官方 FAQ(链接见文末)。以下为对全文的结构化总结。

### 4.1 本质

永续合约 7×24 交易,但标的股票不是。除息日股票会**跳空**,币安执行一次**一次性特殊资金费结算**:
**空头付给多头(负资金费)**,把跳空的价值转移过去,使分红对合约持有人中性。

### 4.2 三个公式其实是同一个:**资金费率 = 除息日股价理论涨跌幅**

| 情况 | 公式 | 说明 |
|------|------|------|
| 现金股息 | `资金费率 = −(D / M)` | D=每股总股息(税前,美股USD/韩股KRW),M=结算时实时标记价 |
| 股票股息(送股) | `资金费率 = −r / (1 + r)` | r=(ratio_new/ratio_old)−1,每股新增股份比例 |
| 现金 + 送股 | `资金费率 = −(D/M + r) / (1 + r)` | 两者叠加 |

**统一推导**(市值守恒):除息时现金 D 被抽走、股份变 (1+r) 股,
新价 = (M − D)/(1+r),则

```
价格涨跌幅 = 新价/M − 1 = −(D/M + r)/(1+r)   ← 即资金费率
```

代入特例即回到另外两个公式:
- r=0 → `−D/M`(纯现金)
- D=0 → `−r/(1+r)`(纯送股)

**参数细节:**
- `r = ratio_new / ratio_old − 1.0`
- `ratio_new` = 公司行动后的股份数;`ratio_old` = 行动前股份数
- ⚠️ `ratio_old` **通常为 1 但不可假设为 1**;反向合并(合股)时 `ratio_old > 1`,此时 r 为负,资金费率为正(多头付空头)。

### 4.3 事件时间线(受控的一次性结算窗口)

**美股合约(美东时间 ET,从 ex_date−1 开始,因 24/7 含隔夜):**

| 日期 | 时间 (ET) | 系统操作 |
|------|-----------|----------|
| ex_date − 1 | 15:30 | 资金费周期改为 1 小时(16:00 生效) |
| ex_date − 1 | 19:30 | 进入「只减仓」模式 |
| ex_date − 1 | 19:30 | 标记价与指数价偏离阈值收紧至 1% |
| ex_date − 1 | 20:00 | 常规资金费结算后,**立即结算特殊股息资金费** |
| ex_date − 1 | 20:01 | 关闭「只减仓」,恢复偏离阈值与标准资金费周期 |

**韩股合约(韩国时间 KST,全部在 ex_date 当天,因无隔夜盘):**

| 日期 | 时间 (KST) | 系统操作 |
|------|-----------|----------|
| ex_date | 03:30 | 资金费周期改为 1 小时(04:00 生效) |
| ex_date | 07:30 | 进入「只减仓」模式 |
| ex_date | 07:30 | 偏离阈值收紧至 1% |
| ex_date | 08:00 | 常规资金费结算后,**立即结算特殊股息资金费** |
| ex_date | 08:01 | 关闭「只减仓」,恢复阈值与周期 |

### 4.4 三道防护(工程精髓)

1. **只减仓模式(only-reduce)** —— 反套利。结算前 30 分钟禁止开新仓,防止有人临结算前开巨额多头白嫖负资金费。想拿补偿必须提前真实持有多头、承担隔夜风险。
2. **偏离阈值收紧至 1%** —— 防操纵。结算按实时标记价 M 计,把标记价钉在指数附近,防止有人拉偏标记价放大/缩小结算额。
3. **故意绕过资金费率上限(funding cap)** —— 保精度。股息调整可能远超日常上限(送股 10% 就是 −9.09%);若照常封顶,多头拿不到完整补偿,除息中性被破坏。故本次主动跳过上限,给足完整数学价值。

### 4.5 数字示例(MU 永续,持仓 10,价格 1000,10 送 1)

```
r = 0.1 → 资金费率 = −0.1/1.1 = −9.09%
仓位          : 10 MU(结算前后都不变)
名义价值      : 10 × 1000 = 10000 USDT
收到资金费    : 10000 × 0.0909 ≈ 909 USDT     (空头→多头)
除息后新价    : 1000 / 1.1 ≈ 909.09
价格浮亏      : 10 × (909.09 − 1000) ≈ −909.1 USDT
净影响        : +909 − 909.1 ≈ 0
```

**反向合并示例(2 合 1):** ratio_old=2, ratio_new=1 → r=−0.5 →
资金费率 = −(−0.5)/(1−0.5) = +100%(多头付空头),对应股价翻倍,净影响仍 ≈ 0。

## 5. 量化 / 对账启示

- **除息不是 alpha**:机制设计得当则净盈亏 ≈ 0。回测若出现"除息日多头稳赚/稳亏",大概率是**漏计了这笔特殊资金费**,是数据 bug 而非策略。
- **对账单独抓这笔特殊 funding**:它紧挨常规 funding 结算但**单独一笔、且不受 cap 限制**,金额可能异常大。对账里"funding 超上限即告警/截断"的逻辑会误杀,需对公司行动开白名单。
- **时区别错**:美股按 ET 且**从 ex_date−1 结算**,韩股按 KST 在 ex_date 当天;落库统一转 UTC,否则日期错一天,持仓快照对不上。
- **只减仓窗口影响执行**:结算前 30 分钟不能开仓;策略若在该时点有开仓逻辑会被拒单,需提前避让相关标的的除息窗口。
- **现金 vs 现金+送股要区分数据源**:r 与 D 来自不同公司行动字段,`ratio_old` 反向合并时不为 1,取错整笔算反。实现上统一用 `−(D/M + r)/(1+r)` 单一路径最稳。
- **现货 vs 合约分开对账**:现货是"数量+成本价重算 / 现金空投",合约是"资金费";两条对账逻辑不可混用。
